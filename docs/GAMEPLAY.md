# 三关玩法与解法

本文只描述 `site/` 实际实现。名称属于游戏比喻，不等同于黑格尔的哲学概念。后续设计方法见 `DESIGN_DIRECTION.md`。

## 目标和操作

实心圆自动向右走，遇到缺口或材料障碍停下。改变通路，让它抵达空心圆。

- “有”／数字键 1：点击虚线空位，消耗一份材料填入。
- “无”／数字键 2：点击已有材料，回收一份材料。第一关完成后获得。
- “重来”／Esc：重置当前关。菜单可重玩已到达的关卡。
- 第三关结束显示“变”作为奖励名称；本包没有定义该名称的可玩操作。
- “再走一遍”：回到第一关。

鼠标、触屏均点按；键盘可用 Tab、Enter 或空格激活按钮。没有生命值、时间限制或错误操作惩罚。

## 规则

材料总量守恒：余量加已填充的可编辑格数等于该关总材料。浅灰固定地面不能编辑；不能抽走圆点当前脚下的支撑，也不能把材料放入圆点所在的行走格。错误操作保持原状态，给出简短提示。

圆点每次向右走一格，控制器等待 620 ms 再推进，画面位移动画为 550 ms。这是离散网格模拟。

## 三关布局

坐标从零计数。横向 x=0..6，角色在 y=3，支撑位于 y=4；页面无障碍标签的编号加一。

| 关卡 | 起始余量 / 总材料 | 通路空位 | 其他材料 |
|---|---|---|---|
| 1 初见 | 2 / 2 | (2,4)、(4,4) | 无 |
| 2 回收 | 0 / 2 | (2,4)、(4,4) | (3,3)、(3,2) 已填 |
| 3 余量 | 1 / 1 | (2,4)、(4,4) | 无 |

### 1 初见

用“有”填两处空位。角色到达终点，获得“无”，自动进入下一关。

### 2 回收

用“无”清空 (3,3) 与 (3,2)，收回材料。切到“有”，填两处通路空位，进入下一关。

### 3 余量

先填 (2,4)。等角色经过它并到达 x=3，回收身后的 (2,4)，再填 (4,4)。角色抵达终点，显示“变”，本次游戏结束。

这些不是唯一解法。规则求解器路径见 `../validation/solution-paths.json`。第二关必须结合回收与放置，第三关需要重复利用。能完成程序目标不证明玩家理解了哲学。
